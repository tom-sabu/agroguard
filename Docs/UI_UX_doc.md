# UI/UX Documentation

## Design Principles
- **Simplicity**: Minimal forms, clear actions.
- **Trust**: Focus on photos and location.
- **Local Feel**: Use terms and data relevant to Kottayam.

## Core Screens
1. **Home/Map Screen**:
    - Full-screen interactive map (Leaflet).
    - Floating card for "Today's Kottayam Prices".
    - "Sell Something" button.
2. **Product Detail**:
    - Large image.
    - Price and description.
    - "WhatsApp Seller" button.
3. **Seller Form**:
    - Image upload field.
    - Title, Price, Category.
    - Auto-detect location (with manual fallback).

## Components (Shadcn UI)
- Buttons for primary actions.
- Cards for map pins and price widgets.
- Modals for forms.
- Toasts for success/error messages.
